# Handbook Feedback 示例

使用此目录记录学习过程中发现的问题、建议、错别字等。

## 反馈格式建议

```markdown
# 反馈标题

## 来源页面
- URL: https://aiweb3.school/zh/handbook/xxx/
- 章节: XXX

## 问题描述
<!-- 描述发现的问题 -->

## 建议改法
<!-- 如果有建议的修改方案 -->

## 补充说明
<!-- 其他相关信息 -->
```

## 示例

### 示例 1：内容建议

**来源页面**: https://aiweb3.school/zh/handbook/bridge/agent-wallet/

**问题描述**: 章节 "Agent Wallet" 目前缺少具体的代码示例，读者可能难以理解如何实现。

**建议改法**: 巻加一个简单的示例，展示如何使用 Account Abstraction 创建 Agent 钱包。

---

### 示例 2：错别字

**来源页面**: https://aiweb3.school/zh/handbook/ai/llm/

**问题描述**: 第 X 段"模行"应为"模型"。

**建议改法**: 修正为"模型"。

---

## 提交方式

1. 在此目录创建 Markdown 文件记录反馈
2. 可以直接提交 PR 到 https://github.com/lxdao-official/aiweb3school
3. 或联系 Handbook 维护团队

---

*感谢你的反馈！每一份建议都会让 Handbook 更好。*
